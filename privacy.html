Privacy Policy: NoyyinPerth Publisher

Effective date: 23 November 2026
Operator: NoyyinPerth ("I", "me"), Perth, Western Australia, Australia
Contact: noyyinperth@gmail.com

1. What this policy covers

NoyyinPerth Publisher (the "tool") is private software that I run on my own computer. It researches topics for, and publishes videos and posts to, my own NoyyinPerth accounts on YouTube, Facebook and TikTok. It isn't offered to the public, and nobody else can sign in to it or connect an account. This policy explains what data the tool accesses, how it's used and stored, and how access can be revoked.

Features marked planned aren't built yet. They're described here so this policy already covers them when they are.

2. Platform services and their policies

  • YouTube API Services. By using this tool you also agree to the YouTube Terms of Service. YouTube's handling of data is described in the Google Privacy Policy: http://www.google.com/policies/privacy.
  • Meta (Facebook) Graph API. Facebook's handling of data is described in the Meta Privacy Policy.
  • TikTok Content Posting API and Login Kit. TikTok's handling of data is described in the TikTok Privacy Policy.

3. Data the tool accesses

The tool connects only to accounts I own or manage, with my permission, through each platform's official sign-in (OAuth). It doesn't access anyone else's account, private messages, comments, followers' or subscribers' personal information, or payment information.

a) My YouTube channel

  • Permissions: youtube.upload (upload videos) and youtube.readonly (read my channel and my videos).
  • Data: my channel's name and ID, used to confirm the right channel is signed in. Also the details of videos I upload (title, description, tags, thumbnail, privacy status, audience setting, altered or synthetic content setting, processing status), which are read back to check the upload worked.

b) My Facebook Page

  • Permissions: pages_show_list, pages_read_engagement and pages_manage_posts.
  • Data:
    • During setup, the list of Pages I manage (name, ID and my role on each), so I can choose the NoyyinPerth Page. Only the NoyyinPerth Page's access token is kept.
    • The Page's name, ID, follower count and link, used to confirm the connection.
    • For each video I upload: its ID, title, description, AI-generated label, draft or published state and processing status.
  • planned Performance statistics for my own posts (for example views and reactions), using Meta's read_insights permission. Only my own posts' totals are read, not information about individual viewers.

c) My TikTok account

  • Permissions: user.info.basic, video.upload and video.publish.
  • Data:
    • My account's open ID and display name, used to confirm the right account is connected.
    • Creator information TikTok provides before posting (username, available privacy options, maximum video length).
    • For each video I post: its publish ID, caption, privacy setting, AI-generated content label and processing status.
  • planned Performance statistics for my own posts, if TikTok makes them available to this tool.

d) Public YouTube data for topic research

  • Retrieved with an API key, no sign-in: search results for medical-education topics, including video titles, channel names, public view, like and comment counts, public subscriber counts, publish dates, video lengths and links.
  • Used only to choose which topics to make original videos about. It's shown as YouTube provides it. I don't create new metrics from it, combine it into profiles of people, or reuse anyone's content.

e) Public health information

  • To fact-check videos, the tool downloads the public pages of trusted health sources (for example Healthdirect, the Royal Children's Hospital Melbourne and the NHS). It then checks that each quoted sentence appears on the page. These pages contain no personal information.

4. How data is used

  • To publish my own videos and posts, and to confirm their details and status on each platform.
  • To choose topics for original health-education content.
  • planned To review how my own posts perform.
  • Data is never used for advertising, never sold or rented, and never shared with data brokers.

5. Storage and retention

  • Sign-in tokens and app keys are stored only on my computer, in credential folders outside source control that only my Windows account can open. They're never published, printed or shared.
    • The Facebook Page token lasts until it's revoked.
    • TikTok access tokens expire after 2 hours. TikTok refresh tokens expire after 180 days and are replaced each time they're used.
    • YouTube tokens last until they're revoked or expire.
  • Records of my own uploads (platform IDs, upload times, draft or published state) are kept with my production files for as long as the videos exist on my accounts.
  • Public YouTube research data is stored only on my computer, and is deleted or refreshed within 30 days of being retrieved. Deletion runs automatically each time research runs.
  • Downloaded health-source pages are cached for up to 7 days and then downloaded again.
  • Nothing is stored on this website or any server I operate.

6. Sharing and service providers

I don't sell or share platform data with third parties, with one exception. I use an AI assistant (Claude, by Anthropic) on my computer to help build and run the tool. When it runs the tool, it can see the tool's output, which may include my research reports, upload status messages and my accounts' names and IDs. That information is sent to Anthropic only to provide this assistance. Sign-in tokens and app secrets are never shown in that output.

The narration voice is generated on my own computer (an open-source text-to-speech model), and speech is transcribed for captions on my own computer as well. No audio is sent to an outside service for either.

7. This website

This website is a few static pages hosted on GitHub Pages. It has no sign-in, forms, cookies, analytics or tracking. GitHub, as the host, may record technical information such as visitors' IP addresses for security purposes, as described in the GitHub General Privacy Statement.

8. Children

The tool doesn't collect any information from viewers, including children.

9. Revoking access and deleting data

  • Google/YouTube: remove the tool's access at Google security settings (myaccount.google.com/permissions).
  • Facebook: remove NoyyinPerth Publisher under Facebook Settings > Business integrations. This cancels the Page token.
  • TikTok: remove NoyyinPerth Publisher from the apps connected to the TikTok account, in the TikTok app's settings.
  • If you'd like data about your public YouTube content removed from my research files before the automatic 30-day deletion, email noyyinperth@gmail.com. I'll delete it within 7 days.

10. Changes

If this policy changes, I'll update this page and its effective date.
